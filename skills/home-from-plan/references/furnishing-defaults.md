# Default furnishing per room kind

Use when the plan shows no furniture in a room (or for symbols you cannot place exactly). Put items against walls without
windows or doors where possible; keep 0.8 m free in front of doors and 0.6 m in front of kitchen units. Mark them
`"basis": "approximate"`. Skip what does not fit — never overlap doors.

| kind | items (catalog ids) |
|---|---|
| bath | `bathtub` (if ≥ 1.7 m free along a wall) or `shower` `90`; `toilet`; `vanity` `60`/`80` + `mirror` `rect` (elevation 1.25); `washer` if space |
| kitchen tag (in kitchen / living) | along one wall: `kitchen-tall` `fridge` or `fridge-freestanding`, `kitchen-base` ×n, `kitchen-cooktop`, `kitchen-sink` (under a window if there is one), `kitchen-dishwasher`; `kitchen-wall` `doors` above base units (elevation 1.5) |
| living | `sofa` `3` facing the longest free wall; `tv-wall` `65` on that wall (elevation 1.0) or `tv-stand`; `coffee-table` `rect` |
| dining (living with space) | `dining-table` `4`/`6` + `dining-chair` ×4–6 |
| bed | `bed` `160` (`90` for single rooms < 9 m²) head against a wall, `bedside-table` ×2, `wardrobe` `2d`/`3d` |
| office | `desk` under / next to a window, `office-chair`, `shelves` |
| hall | `cabinet` `low` + `mirror` `rect` (elevation 1.05) |
| storage, tech, garage | `shelving` (garage: `workbench`) |
| room (unknown use) | nothing — ask the user what it is |
